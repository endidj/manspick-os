# 브랜드 사진

[Figma 99 Assets](https://www.figma.com/design/cDXVLqZAaWwZeyIo5pqnNl/?node-id=12-4)에서 2026-11-06 로그인된 브라우저의 네이티브 내보내기로 이미지 레이어 **47개**를 각각 PNG 3x로 가져왔다. 이전 문서의 38개 목록에 styling 2~9·12를 더한 실제 수량이다. 완성된 화면을 이미지로 대체한 것이 아니다.

- `originals/`: 내보낸 PNG 원본, 540×720px, 총22,612,477바이트. 원본 바이트를 보존한다.
- 같은 이름의 `.webp`: 크기·크롭을 유지한 quality88 압축본, 총2,300,354바이트. 앱은 이 파일을 쓴다.
- `figma-export-manifest.json`: 원본·압축본의 SHA-256과 파일별 크기·치수·출처.
- `brand-images.ts`: `@manspick/design-system/assets`의 `brandImages['hero-after-1']` 등으로 가져오는 공개 URL·치수.

변신12·보정6·장소3·소품8·스타일링12·팀2·기타4종이다. 사진에 포함된 인물·상표의 권리는 원 권리자에게 있으며 프로젝트 구현용으로 제공된 파일이다. 외부 재배포 권한이나 고객의 신규 포트폴리오 동의를 뜻하지 않는다. 실제 고객 업로드는 이 폴더에 넣지 않는다.
