# 공개 사이트 상담 아이콘

원본 manspick-site가 사용하는 Iconify `ri:kakao-talk-fill`과 `mdi:instagram`의 SVG 원본이다. 공개 저장소의 기존 데모 glyph와 구분해 운영 사이트 모습을 보존한다.

- [Remix Icon 원본 라이선스](https://github.com/Remix-Design/RemixIcon/blob/master/License).
- [Material Design Icons 라이선스 안내](https://pictogrammers.com/docs/general/license/). Brand/Logos는 일반 Apache 라이선스 범위에서 제외되므로 채널 안내 외 로고 권리를 주장하지 않는다.
- `gallery-wide-bold-duotone.svg`: [Solar Icon Set](https://github.com/480-Design/Solar-Icon-Set), 원본 사이트에서 사용하는 추가 갤러리 아이콘.
- 취득 경로: `https://api.iconify.design/ri/kakao-talk-fill.svg`, `https://api.iconify.design/mdi/instagram.svg`.
