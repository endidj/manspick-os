# 맨즈픽 운영 앱

운영직원은 고객·주문과 수납 상태를 확인하고 문의에 응대합니다. 디렉터는 배정된 고객의 설문을 보고 촬영 일정과 장소를 확정합니다. 대표는 직원과 운영 설정을 관리하고 별도 지표 페이지에서 주문·설문 전환을 확인합니다. [제품 요구사항](../../docs/product-requirements.md)

## 실행과 로그인

루트에서 `yarn dev`를 실행하고 [운영 앱](http://localhost:3002)을 엽니다. 로컬과 공개 테스트에서는 대표·운영 직원·디렉터·보정가 중 하나를 골라 가상 직원으로 로그인합니다. 운영 환경은 허용된 회사 도메인으로 직원 로그인 메일을 보냅니다. [서버 설정](../server/README.md#환경과-검사) · [공개 테스트 환경](../server/README.md#통합-테스트-환경)

## 주요 화면

| 화면           | 경로                                  | 할 수 있는 일                                                  |
| -------------- | ------------------------------------- | -------------------------------------------------------------- |
| 고객 보드·목록 | `/?view=board`, `/?view=list`         | 고객 검색, 기간·상품·담당자 필터, 수동 접수                    |
| 고객 상세      | `/shoots/:id`                         | 수납 확인, 설문·요청 조회, 안내 템플릿, 내부 메모·사진 관리    |
| 배정·스케줄    | `/?view=calendar`                     | 디렉터 후보·업무량·주간 일정 확인, 배정 변경                   |
| 디렉터 업무    | `/?view=my-customers`, `/?view=today` | 내 고객, 오늘 촬영, 희망 일정 확정, 현장 체크                  |
| 상품·안내      | `/?view=packages`, `/?view=templates` | 패키지와 옵션, 단계·상품·담당자별 안내 문구 관리               |
| 운영 설정      | `/?view=settings`                     | 직원 역할과 활성 상태, 계좌·장소·준비 가이드, 변경 이력        |
| 운영 지표      | `/metrics`                            | 관리자 권한으로 랜딩 행동, 자사 주문 이탈, 인증·설문 전환 확인 |

직원 역할·활성 상태를 변경하면 기존 세션과 미사용 로그인 링크를 회수합니다. 디렉터는 배정된 촬영에 접근하고 보정가 메뉴에는 내 정보가 표시됩니다. 화면 접근과 데이터 변경 권한은 공통 서버에서 검사합니다.

수동 등록도 고객 접수와 같은 예약 API를 사용합니다. 상품이나 운영 기한을 수정하면 새 예약부터 적용됩니다. 안내 문구는 조건에 맞는 템플릿을 골라 직원이 카카오채널에서 발송하고 화면에 완료를 기록합니다. 결과 전달은 네이버 클라우드, 보정 의견 교환은 카카오톡에서 진행합니다.

## 수정할 곳과 검증

메뉴·역할별 기본 경로는 [workspace/model.ts](src/features/workspace/model.ts), 고객 상세와 일정 확정은 [shoot-detail](src/features/shoot-detail/), 상품·직원·템플릿 설정은 [operations](src/features/operations/)에서 관리합니다.

루트의 `yarn test`는 메뉴 접근과 업무 규칙을 검사합니다. 운영 앱을 실행한 뒤 아래 명령으로 모의 API 응답을 사용하는 브라우저에서 수동 접수와 일정 화면을 검사합니다.

```powershell
$env:ADMIN_APP_URL = 'http://127.0.0.1:3002'
node --test tests/manual-registration.browser.test.mjs tests/admin-schedule.browser.test.mjs
```
